# Acknowledgments

## Origin

ebot (Expedient Bot) is a fork of the excellent [Obot platform](https://github.com/obot-platform/obot), developed by the Obot team.

## About Obot

Obot is an innovative open-source platform for implementing Model Context Protocol (MCP) technologies. The original Obot platform provides:

- MCP server hosting (Docker & Kubernetes)
- MCP registry for server discovery
- MCP gateway for access control
- Feature-rich chat client with RAG support
- Comprehensive API and integrations

## Our Customization

ebot builds upon Obot's solid foundation with enterprise-focused enhancements tailored for Expedient's specific needs:

- **Enhanced Compliance**: HIPAA, SOC 2, GDPR features
- **Cost Management**: Comprehensive usage metering and chargeback
- **Enterprise Security**: Advanced encryption, audit logging, and access control
- **High Availability**: Production-grade HA/DR capabilities
- **Multi-Region Support**: Data residency and regional deployment
- **Resource Management**: Quotas, capacity planning, and performance optimization

## Thank You

We are grateful to the Obot team and the open-source community for creating such a well-architected platform. Their work provided an excellent starting point for building an enterprise-ready MCP platform.
